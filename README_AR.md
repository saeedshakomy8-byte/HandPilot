# HandPilot — التحكم باللابتوب بإشارات اليد

نسخة تجريبية أولية لـ Windows 11 تستخدم كاميرا اللابتوب.

## الوظائف الحالية
- وضع MOUSE: تحريك المؤشر بالسبابة، النقر بضم الإبهام والسبابة، والتمرير بإظهار السبابة والوسطى.
- وضع VOLUME: رفع/خفض الصوت بحسب ارتفاع السبابة، وتغيير السطوع بإظهار السبابة والوسطى، وكتم/إلغاء كتم الصوت بالقبضة.
- كف مفتوح للتبديل بين وضع الماوس ووضع الصوت/السطوع.
- اضغط Q أو Esc لإغلاق البرنامج.

## التثبيت
1. ثبّت Python 3.11 (64-bit) من https://www.python.org/downloads/release/python-3119/ مع تفعيل **Add python.exe to PATH**.
2. افتح مجلد HandPilot في File Explorer، واكتب `cmd` في شريط العنوان ثم Enter.
3. نفّذ الأوامر التالية واحدًا تلو الآخر:

   ```bat
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python app.py
   ```

4. بعد نجاح التثبيت، يمكنك تشغيل `run.bat` في المرات التالية.

## ملاحظات السلامة والتوافق
- اسمح لـ Python باستخدام الكاميرا من إعدادات الخصوصية في Windows.
- التحكم بالسطوع يعمل على شاشات كثيرة، لكنه قد لا يعمل على كل شاشة خارجية.
- دقة التعرف على الإشارات تعتمد على الإضاءة وموقع اليد، وقد تحتاج لضبطها حسب الكاميرا.
- هذا نموذج أولي غير مختبر على كل الأجهزة؛ لا تستخدمه لتنفيذ أوامر حساسة أو أثناء عمل مهم.
- للإيقاف: اضغط Q أو Esc في نافذة الكاميرا، أو حرّك المؤشر إلى الزاوية العلوية اليسرى لتفعيل حماية PyAutoGUI.
- لا يرسل التطبيق الفيديو إلى الإنترنت؛ تتم المعالجة محليًا على الجهاز.
